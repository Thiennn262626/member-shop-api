# Member Shop Backend API (member-shop-api)

Dự án Backend cho Hệ thống Quản Lý Tiệm Bánh & Đồ Uống Tích Điểm Hội Viên **Bake & Sip**.

- **Ngôn ngữ:** Golang 1.24
- **Cơ sở dữ liệu:** MongoDB (Official Driver)
- **Caching:** Redis (`pkg/cache`)
- **Logging:** Zerolog + Lumberjack (`pkg/logger`)
- **Realtime:** Server-Sent Events (SSE)

Xem chi tiết kiến trúc, 10 collection schema, và danh sách REST API tại:
- `../BACKEND_ARCHITECTURE_PLAN.md`
